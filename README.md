# rust_nets
Ejercicios de programación y visualización de redes neuronales con rust

Material producido gracias al apoyo del **Proyecto PAPIME PE104425: Visualización Animada en 3D de Redes Neuronales**

## Instrucciones de uso

1. Para utilizar ```cifar_metaoptim``` y ```cifar_rust``` es necesario descargar el conjunto de datos.  Para ello se utiliza el guión ```load_cifar.py``` según se indica en el directorio ```cifar_rust```.
