# Perceptrón

En este repositorio se ejemplifica el proceso completo para analizar el comportamiento de un perceptrón durante su entrenamiento y uso con el conjunto de datos [Iris]().

## Conjunto de datos

1. Descargar el conjunto de datos [Iris](https://archive.ics.uci.edu/dataset/53/iris) dentro de un directorio ```data```, al lado de ```src```.
2. Descomprimir el ```.zip``` ahí mismo.

## Ejecución del programa

1. Ejecutar con ```cargo```:

```
cargo run
```
